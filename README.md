# Gesture_Based_Fighting_Game

## SFML setup

The Visual Studio project uses a local `SFML_DIR` path instead of hardcoded install paths.

Set `SFML_DIR` on each machine to your SFML root folder before building, for example:

`C:\SFML-2.6.2\`

The repository should contain source and project files only. Machine-specific Visual Studio files such as `*.user` stay local and should not be committed.
